RemyVisuals — Fabric 1.21.11

СБОРКА БЕЗ УСТАНОВКИ ЧЕГО-ЛИБО (через GitHub):
 1. Создай репозиторий на github.com и загрузи в него ВСЕ файлы этой папки (включая папку .github).
 2. Открой вкладку Actions -> build -> дождись зелёной галочки.
 3. Внизу страницы запуска, в Artifacts, скачай RemyVisuals-jar и распакуй zip.
 4. Файл RemyVisuals-1.0.0.jar (НЕ -sources) положи в .minecraft/mods вместе с Fabric API.

СБОРКА ЛОКАЛЬНО: JDK 21 + Gradle 8.14+, в папке выполни: gradle build
Готовый мод: build/libs/RemyVisuals-1.0.0.jar

В игре: Right Shift — меню. ЛКМ по модулю — вкл/выкл, ПКМ — настройки (если есть).
